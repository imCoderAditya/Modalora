1. Executive Summary & Architecture

Modalora was architected to solve the fragmentation, rigidity, and boilerplate of traditional Flutter overlay widgets (showDialog, showModalBottomSheet, ScaffoldMessenger, tooltips, and custom overlays). Modalora unifies every overlay paradigm into a single, cohesive, developer-first design system with zero external package dependencies.

Core Architectural Pillars:
  • Unified Facade Engine: Complete control via Modalora.* top-level methods.
  • Contextless Overlay Dispatch: Global ModaloraConfig.navigatorKey allows triggering modals from BLoC, Riverpod, or background jobs.
  • 4-Tier Property Priority Cascade: Inline Override → Component Theme → Global Theme → System Default.
  • Hardware-Accelerated Frosted Glass: Native backdrop blur and crystalline specular highlights.

Architecture Hierarchy

📦 Core Engine Layer
ModaloraConfig global state, ModaloraOverlayController, ModaloraSnackbarQueue, and screen size responsive breakpoint calculators.
🎨 Design Token System
ModaloraThemeData, ModaloraDialogTheme, ModaloraBottomSheetTheme, ModaloraMenuTheme, and dark/light adaptive presets.
⚡ Animation Physics
ModaloraAnimation builder supporting spring physics, customizable dampening, scale/fade combinations, and custom transitions.
🌌 Spatial 3D Engine
Matrix4 perspective distortion with real-time pointer/gyro tilt, specular radial light sheen, and pulsing orbital glowing rings.

3D Hologram & Spatial Tilt Specification

The Modalora3DTiltCard applies a perspective matrix transformation using: 

Matrix4.identity()
  ..setEntry(3, 2, perspective) // 0.0018 perspective depth
  ..rotateX(_tiltX)             // Angular tilt on Y-axis pointer movement
  ..rotateY(_tiltY);            // Angular tilt on X-axis pointer movement

Accompanied by an overlaid RadialGradient with dynamic focal position that computes real-time specular light reflections across the glass surface.

3. Code Implementation & Starter Suite

Below is the complete, self-contained main.dart demonstrating all 7 primary interactive entry points: 

import 'package:flutter/material.dart';
import 'package:modalora/modalora.dart';

final GlobalKey<NavigatorState> navigatorKey = GlobalKey<NavigatorState>();

void main() {
  Modalora.configure(
    navigatorKey: navigatorKey,
    theme: ModaloraThemeData.dark(primaryColor: const Color(0xFF6366F1)),
  );
  runApp(const ModaloraApp());
}

class HomeScreen extends StatelessWidget {
  const HomeScreen({super.key});

  @override
  Widget build(BuildContext context) {
    final GlobalKey popupKey = GlobalKey();

    return Scaffold(
      body: Column(
        children: [
          // 1. Glass Dialog
          ElevatedButton(child: const Text('1. Dialog'), onPressed: () => Modalora.dialog(title: 'Saved')),
          
          // 2. Bottom Sheet
          ElevatedButton(child: const Text('2. Bottom Sheet'), onPressed: () => Modalora.bottomSheet(title: 'Filter')),
          
          // 3. Top Sheet
          ElevatedButton(child: const Text('3. Top Sheet'), onPressed: () => Modalora.bottomSheet(alignment: Alignment.topCenter, title: 'Top Bar')),
          
          // 4. Anchor Popup
          ElevatedButton(key: popupKey, child: const Text('4. Popup'), onPressed: () => Modalora.popup(anchorKey: popupKey, title: 'Tip')),
          
          // 5. Toast Snackbar
          ElevatedButton(child: const Text('5. Toast'), onPressed: () => Modalora.snackbar(title: 'Sync Active', showProgressBar: true)),
          
          // 6. Orbital Loader
          ElevatedButton(child: const Text('6. Loader'), onPressed: () async {
            final handle = Modalora.loading(title: 'Syncing...');
            await Future.delayed(const Duration(seconds: 2));
            await handle.dismiss();
          }),
          
          // 7. 3D Hologram Modal
          ElevatedButton(child: const Text('7. 3D Hologram'), onPressed: () => Modalora.hologram(title: '3D Spatial Engine')),
        ],
      ),
    );
  }
}
